Artsake: Django Migration Developer Guide

Welcome to the Artsake storefront migration project. We are transitioning this site from Shopify to a custom Django application. Please follow these strict guidelines to ensure the static assets and templates render correctly in the Django environment.

1. The File Structure

Our project follows standard Django conventions. Your working directories are structured as follows:

  • Templates: artsake/templates/pages/index.html
  • Stylesheets: artsake/static/css/
  • Images: artsake/static/images/ (with a web/ subfolder)
  • Fonts: artsake/static/fonts/

2. The Golden Rule: Load Static

Because Django separates HTML templates from static assets (like images, CSS, and fonts), you cannot use standard HTML relative paths for your assets.

At the very top of your index.html file (Line 1), you must include the following tag. If this is missing, Django will crash when trying to load assets.

{% load static %}

3. Linking CSS Files

The project relies on three primary, sanitized CSS files. When linking them in the <head> of your HTML, you must wrap the paths in the Django static tag format so the server knows to look in the static/css/ directory.

<!-- Include these in the <head> of your HTML -->
<link rel="stylesheet" href="{% static 'css/customstyles_2.css' %}">
<link rel="stylesheet" href="{% static 'css/artsake-sections_3.css' %}">
<link rel="stylesheet" href="{% static 'css/2026-art-for-hospitalty-hero_2.css' %}">

4. Sourcing Images

Most of the project images are nested inside the artsake/static/images/web/ folder. You cannot write standard src="images/web/logo.png" tags.

Wrap the image path inside the static tag like this:

<!-- For standard images in the main images folder -->
<img src="{% static 'images/logo.png' %}" alt="Artsake Logo">

<!-- For images inside the 'web' subfolder -->
<img src="{% static 'images/web/Art_for_Hospitality_Banner.png' %}" alt="Hospitality Banner">

5. Handling Fonts in CSS

📝 REQUIRED FONTS:

The official typography for this project utilizes three specific font families: OUTFIT, NOTO SERIF, and Benton Sans Extra Comp. Please ensure these are the only fonts applied across the components and global styles.

Because Django serves everything out of the root static folder, the CSS files in the css/ folder need to know how to find the fonts/ folder.

In your CSS files, use a relative path that jumps up one directory to access the fonts:

@font-face {
    font-family: 'Outfit';
    src: url('../fonts/Outfit-Regular.woff2') format('woff2');
}

6. No Shopify Liquid Allowed

This is a transition away from Shopify. Django uses Python and Jinja-style templating. You may encounter legacy code snippets.

⚠️ CRITICAL:

Any old Shopify tags (e.g., {{ settings.color_body_text }} or {% assign color_main_bg = settings.color_main_bg %}) will cause fatal syntax errors in Django. Do not copy/paste raw Liquid logic into the Django HTML or CSS files. Use standard CSS variables and standard Django template tags only.
